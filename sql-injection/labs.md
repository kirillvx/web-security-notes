# SQL Injection Labs (Completed)

## Authentication Bypass
- Basic login bypass
- Bypass with different payloads

## UNION Attacks
- Determining the number of columns returned by the query
- Finding a column containing text
- Retrieving data from other tables
- Retrieving multiple values in a single column

## Examining the Database
- Querying database type and version (MySQL, Microsoft)
- Listing database contents (non-Oracle databases)

## Blind SQL Injection
- Conditional responses (boolean-based)
- Time delays and data extraction (time-based)
- Out-of-band interaction (OAST)
- Out-of-band data exfiltration

## Error-Based SQL Injection
- Extracting data using database errors
